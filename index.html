同盟メンバー 名前チェッカー

プレイヤーIDから現在のゲーム内ニックネームを確認し、名前が変わったメンバーを一覧で把握するツールです。
実際の名前の取得は、GitHub Actionsが行い、その結果(data.json)をこのページが表示しています(このページ自体は直接ゲームのAPIを呼び出していません—ブラウザからだとCORSでブロックされるため)。 下の「メンバーを追加」フォームからIDを追加すると、GitHub上のmembers.jsonが自動更新され、名前の取得も自動的に始まります。 使用しているAPIは非公式のもの(justncodes/wos-giftcode の実装を参考にしたもの)です。運営会社の仕様変更で動かなくなる可能性がある点はご了承ください。

設定: GitHubトークン 未設定

トークンの取得方法(初回のみ・1〜2分で終わります)
  1. GitHub右上のアイコン→「Settings」
  2. 左メニュー一番下「Developer settings」
  3. 「Personal access tokens」→「Fine-grained tokens」→「Generate new token」
  4. Token name: 任意(例: wos-name-checker-web)、Expiration: 任意(例: 90日)
  5. Resource owner: このリポジトリを持っているアカウント(mog-alliance)
  6. Repository access: 「Only select repositories」を選び、wos-name-checkerのみ選択
  7. Permissions → Repository permissions で以下の2つを「Read and write」に設定:
    • Contents
    • Actions
  8. 「Generate token」を押し、表示された文字列(github_pat_...)をコピーして下の欄に貼り付け

このトークンは、このリポジトリだけを書き換えられる「合言葉」です。他人に教えたり、他のサイトに貼り付けたりしないでください。ブラウザのタブを閉じると自動的に忘れます(保存はされません)。
